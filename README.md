 # Apna-Hisab
 🧠 Overview

Apna Hisab is a smart personal finance management application designed to help users automatically track their daily expenses and income with minimal manual effort.
The app focuses on simplicity, automation, and privacy, making it especially useful for students, working professionals, and small households.

Unlike traditional expense trackers that require users to manually enter every transaction, Apna Hisab intelligently reads SMS alerts from banks and wallets, extracts meaningful financial information using Machine Learning & NLP, and automatically categorizes transactions.

The goal of Apna Hisab is simple:

“Let users focus on their life, while Apna Hisab takes care of their money records.”


 🎯 Problem Statement

-Managing personal finances is difficult because:

-People forget to record daily expenses

-Manual entry is time-consuming and boring

-Bank statements are hard to analyze

-Existing apps are complex and data-heavy

-Privacy concerns with cloud-based storage



 ✅ Solution Provided by Apna Hisab

Apna Hisab solves these problems by:
  
  -Automatically reading transactional SMS

  -Detecting expense or income using ML

  -Categorizing transactions (Food, Travel, Bills, Shopping, etc.)

  -Storing data locally for better privacy

  -Showing clean summaries and insights


 📊 Categories Supported

  -Food & Dining

  -Travel & Transport

  -Shopping

  -Bills & Utilities

  -Entertainment

  -Education

  -Health

  -Miscellaneous
